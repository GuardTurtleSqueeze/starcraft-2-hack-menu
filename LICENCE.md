## 🧩 About

**StarCraft 2 Companion** is a curated list of StarCraft 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, minimap overlay
- **Quality-of-Life Helpers** — build order catalog, hotkey manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Minimap Overlay — enhanced minimap with resource and unit indicators
- Build Order Notes — in-game overlay for build orders and timings
- Replay Notes — record and review match runs
- Playback Speed — adjust replay speed for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse unit skins, decals, and portraits
- Custom UI Notes — organize interface layouts
- Enhanced Selection — improved unit selection visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Resource Tracking — monitor resource flow for study
- Hotkey Manager — customize and review hotkey layouts
